# Agent instructions

This project is developed by multiple coding agents. Follow `.cursor/rules/agent-handoff.mdc` on every session:

1. Document first (`HANDOFF.md`, `MILESTONES.md`).
2. Write failing tests second.
3. Implement features third.
4. Commit and push to `origin` after each coherent unit of work.

Do not expand a scoped PR. Out-of-scope milestones stay `TODO` and get their own later PR.
